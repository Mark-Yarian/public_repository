# Submitting Public Research Material

Research proposals and drafts are evaluated through an internal review process. This repository does not accept confidential, proprietary, unpublished experimental data or secrets.

## Minimum publication package
- Proposed public title, abstract, authors, affiliations, and manuscript type.
- Specific scientific question; related work and references with working links.
- Clear separation of established knowledge, hypotheses, models, measurements and speculation.
- Reproducible methods and non-sensitive public data where results are claimed, or an explicit statement that the article is conceptual.
- Limitations, negative findings, conflicts of interest, and rights/attribution notes.
- Explicit human approval of the exact release version after scientific and IP/security review.

## Safety
Do not open public GitHub issues or pull requests containing sensitive manuscripts, invention disclosures, unpublished methods, API keys, private configuration, source topology, private logs, or raw user data. GitHub public branches and PRs are publicly readable even before merge.

No submitted content is automatically published. The publisher may decline work or request changes.
