# Public Research Release Workflow

**Current mode: MANUAL, FOUNDER-GATED. No autonomous publishing or scheduling is enabled.**

## Lifecycle
1. **Intake, private:** research candidate is recorded with provenance, source attribution, evidence status and domain classification in the existing approved editorial workflow.
2. **Science review, private:** author/editor checks novelty against published literature, factual accuracy, reproducibility, experimental limits and negative results.
3. **Disclosure review, private:** legal/IP and security screening evaluates not only literal details but whether apparently harmless combinations reveal protected work.
4. **Public-safe preparation, private:** create an independently written manuscript, abstract, public citations and metadata; do not redact a proprietary document and assume the remainder is safe.
5. **Exact-version authorization:** founder approves the final bytes (digest), title, attribution, version, target repository/path, license, and any external distribution channels.
6. **Publication:** an authorized writer commits only approved artifacts. No public branch, public PR, GitHub issue, tag, release, or Actions artifact is a safe staging area for confidential information.
7. **Readback:** verify GitHub URLs, file contents/digests, metadata, links and whether the public index accurately reflects the release.
8. **Distribution:** only separately approved channels may receive the final public URL. Any social post has its own reviewed version and approval.
9. **Correction:** record an erratum/supersession; never pretend published material can be erased from public history.

## One-time pilot before considering schedules
Use a *non-scientific* repository test notice to prove document creation, commit, indexing and readback. Then run a separately authorized end-to-end editorial test using a safe synthetic submission, verifying actor-scoped access and that draft/rejected materials never appear publicly. Only after founder acceptance may any scheduler be proposed, with exact scope, timing, cost, review and revocation safeguards. A schedule may prepare a private draft; it must **never bypass individual publication approval**.

## Minimum release receipt (maintained in the approved private workflow)
- content ID and approved version
- exact public target path and immutable commit
- source review / factual checks and unresolved limitations
- IP, security, rights and attribution screening outcome
- approving founder's exact authorization
- destination links and public readback proof
- whether any external syndication was approved and verified
