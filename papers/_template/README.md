# Paper Folder Template (Not a Published Paper)

**Status:** TEMPLATE_ONLY. This folder is an empty public formatting reference, not a submitted manuscript or assigned publication identifier.

For a fully approved release, create a separately numbered folder with:
- `README.md`: public summary, evidence status, authors and link to final artifact
- `abstract.md`: approved public abstract
- `metadata.json`: publication/citation metadata; real identifiers only
- `paper.pdf`: final authorized PDF if the paper format uses PDF
- optional publicly licensed figures and references

A manuscript stays **outside public GitHub** until the exact complete package has passed independent claims, intellectual-property, security, privacy, rights and founder review.

An accepted conceptual paper must not be labeled peer reviewed or experimentally validated unless that status is independently documented. No real paper ID is assigned by this template.
