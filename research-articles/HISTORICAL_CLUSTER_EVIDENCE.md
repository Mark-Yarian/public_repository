# Historical Cluster Evidence Ledger (2025–2026)

**Public research evidence · Compiled 2026-11-13 · Historical source inspection, not a new controlled experiment · Not peer reviewed**

This ledger connects existing SynapticSteel articles to recovered 2025–2026 Cluster and ContinuityNode source and archival JSON. It is not a reproduction of original code, credentials, model weights or raw event logs. Source files were inspected in five historical development folders on an authorized machine; selected local copies were independently checked against SHA-256 manifests. Runtime metrics below remain historical *system-reported claims* unless specifically described as source inspection. No old build was restarted for this edition.

## Preservation and disclosure boundary

The five examined folders held 174,532 files (29.55 GB). The selective historical archive independently preserved 105,501 files (3.12 GB original content), with per-file hashes checked across six private compressed packages. The remaining 69,031 files (26.43 GB), including substantial databases, cached models and dependencies, were **not** independently copied. They remain in their original locations and are represented by a metadata inventory only. A static review inspected 473 source artifacts, and 286 of 290 selected Python files parsed in Python 3.11. Four historical source files contained syntax faults. These totals describe archival coverage, not running-system performance.

## Six falsifiable research directions

1. **Health truth:** compare self-reported status against source-linked useful completion with idle, missing-observer and workload-injection controls.
2. **Lineage versus evolution:** compare latest-version promotion, ordinary rollback and a capability-preserving lineage archive with matched evaluation budget and held-out task performance.
3. **Cognitive workload balance:** compare unbounded task generation, backpressure, deduplication and adaptive-rate policies on identical event traces; report completed work and all failures.
4. **Organism continuity:** compare new identity, clone, restart and bounded descendant with and without retained history; independently test useful retained behavior.
5. **Distributed models:** compare one model, fixed-role fallback and cooperative routing with equal resource budgets, delayed messages and unavailable-node controls.
6. **Multirate regulation:** compare reactive controls, temporal memory and memory-plus-resource regulation on identical pressure and transition traces.

These are **proposed experimental protocols, not results**. A historical healthy, equilibrium, ready, ok, model_loaded or score field is a record of reporting behavior rather than independently calibrated capacity. Source code that tracks lineage is not proof of autonomous inheritance, and computational metaphors are not biological equivalence.
