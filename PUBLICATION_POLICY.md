# Public Research Publication Policy

Status: ACTIVE PUBLICATION STANDARD | Established 2026-11-08

This public library distributes selected, explicitly approved scientific and technical work. Presence in this repository does **not** imply peer review, experimental validation, product availability, patent status, or permission to reuse unpublished material.

## Release rule
Only material explicitly approved by the publication owner for the *exact file version and destination* may be committed as a substantive research publication. Drafting, review completion, pull request creation, a bot recommendation, a scheduled job, or an earlier release approval is not authorization to publish a different revision.

## Required review
1. Verify every factual claim and citation against the cited work.
2. Label hypotheses, examples, simulations, experiments, and measured results distinctly.
3. Confirm ethics, privacy, authorship, copyright, permissions, and licensing.
4. Require an intellectual-property and security review. When uncertain, **withhold** the material and request qualified review before any public upload, including a public branch or pull request.
5. Confirm that no internal files, code, unique technical methods, formulas, configuration, runtime architecture, source maps, raw records, datasets, access details, or sensitive metadata are exposed directly **or inferentially**.
6. Confirm that figures and examples were created specifically for public use or are appropriately licensed.
7. Bind the approval to an immutable revision or content digest, identified destination, author, reviewer, and release version.
8. Verify the published file, links, and metadata after release. Record an evidence-based receipt privately.

## Default on doubt
**WITHHOLD**. Do not publish partial clues or reconstructed technical descriptions merely because literal source code was removed. A patent or legal professional should assess potentially novel subject matter before release.

## Public state vocabulary
- `INDEX_ONLY`: catalog/infrastructure, no released paper.
- `PUBLISHED_WORKING_PAPER`: author-released paper, not peer reviewed unless stated.
- `PEER_REVIEWED`: only with independently verifiable publication evidence.
- `CORRECTED` / `RETRACTED`: prior versions remain acknowledged; explain changes transparently.

## Editorial and operational boundaries
No automatic public commit, social syndication, or timed publication is enabled by this policy. A successful non-scientific infrastructure test does not authorize a research paper release or recurring schedule. Individual releases still require explicit approval.

The public library is never an authority for operational status, proprietary designs, or confidential research.
