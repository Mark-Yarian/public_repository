# Public Figures

Only explicitly approved, independently public-safe, appropriately licensed illustrations may be stored here.

Do not upload internal architecture diagrams, model-flow captures, code or database screenshots, raw experiment traces, endpoint maps, or sanitized-but-reconstructable proprietary figures.

Each figure should identify its creator, source, permission/license, intended paper and whether it illustrates a conceptual example or measured evidence.

No scientific figures are released in this initial infrastructure setup.
